# Scikit-learn Practice

This repository contains my hands-on practice and learning journey with **Scikit-learn**, a Python library used for Machine Learning.

The repository includes Jupyter notebooks covering data preprocessing, Scikit-learn utilities, matrices, and practical implementation of Machine Learning concepts.

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/sakshirai145/ML.git
   ```

2. Navigate to the project directory:

   ```bash
   cd ML
   ```

3. Install the required libraries:

   ```bash
   pip install numpy pandas matplotlib scikit-learn jupyter
   ```

4. Launch Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

5. Open the notebooks and explore the implementations.
